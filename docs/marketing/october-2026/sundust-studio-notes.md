# Sundust — native studio direction

Five iPhone images cover flight, exploration on foot, construction, orbital map and the story chart. Four iPad images use independent native iPad captures. The game supports portrait; original Apple hardware fits each native capture without letterboxing. Three clean and two layered phone views; three clean and one layered iPad view. Only construction cards and a complete chart region are enlarged from original game pixels. The golden planetary sticker is original decorative artwork, generated with the built-in image tool; prompt and hash are in assets/sundust/provenance.json.

Website video sections are paused globally. No store submission or new voice synthesis occurred. Copy lives separately in locales/en-US.json.
